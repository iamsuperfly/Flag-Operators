# Flag-Operators

**Official submission for FlagOS Open Computing Global Challenge (Season 1) – Track 1: Operator Development**

Optimized and high-performance operators for **FlagGems** (the core operator library of FlagOS).

**Goal**  
Improve selected operators from the official 20-task list to make them faster, more memory-efficient, and cleaner for the FlagOS ecosystem.

**Tech Stack**  
- Python + Triton  
- FlagGems (official repository)  
- Full benchmarking and testing

**Status**  
In active development for the hackathon.

Built with focus on solid, production-ready contributions.
